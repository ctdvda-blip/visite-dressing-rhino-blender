# Rendu Rhino + Blender — visite virtuelle d'un dressing

Visite 3D interactive (Three.js 0.169) d'un dressing vitrine modélisé dans Rhino 8 puis mis en lumière
pour Blender/Cycles : chêne clair à lames, vitrines rétroéclairées, lustre, lampadaire, tapisserie marbre doré.

**Ouvrir la visite : https://ctdvda-blip.github.io/visite-dressing-rhino-blender/**

Commandes : orbite à la souris, boutons de points de vue, « Visite libre » avec Z Q S D / W A S D, Échap pour sortir.

Version v0.1-261027.
